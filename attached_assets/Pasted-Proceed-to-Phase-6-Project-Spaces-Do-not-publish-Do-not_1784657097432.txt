- ora assets
- file uploads

- memories

2. Backend project model:
Create default personal Ora project for each user.
Support:
- create project
- list projects
- rename project
- archive project
- restore project if needed
- select current project
- project-scoped assets
- project-scoped conversations
- project-scoped memories
- project-scoped file revisions
- project-scoped generated images/files

3. Project context flow:
projectId must flow through:
- chat
- chat/stream
- upload
- file generation
- file editing
- asset library
- conversation history
- memory
- image generation/editing if applicable

4. Isolation:
No cross-user leakage.
No cross-project leakage.
A file uploaded in Project A should not appear in Project B unless explicitly copied.
A memory saved in Project A should not affect Project B unless marked global.
