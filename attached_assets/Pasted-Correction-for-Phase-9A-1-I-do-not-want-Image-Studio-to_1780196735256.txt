Correction for Phase 9A-1:

I do not want Image Studio to be only a separate sidebar page.

I want Ora itself to be able to generate and create images inside the chat, similar to how ChatGPT can generate images.

The user should be able to ask Ora:

* “Create a logo for my app”
* “Generate an app icon”
* “Make a futuristic AI atom icon”
* “Create a hero image for my website”
* “Create a social media banner”
* “Generate a report cover image”
* “Make a 3D mechanic app icon”
* “Create a professional business graphic”
* “Generate a picture in realistic/cartoon/3D/minimal style”

Ora should understand this as an image generation request and route it to the Image Studio backend/service.

Important design:

Ora = conversational interface and command center
Image Studio backend = provider, storage, safety, credits, asset library, image jobs

So the flow should be:

1. User types image request in Ora chat.
2. Ora detects image-generation intent.
3. Ora asks clarifying questions only if needed:
    * style
    * purpose
    * aspect ratio
    * quality
    * number of variations
    * transparent background
4. Ora calls the secure backend image generation route.
5. Backend uses server-side provider key.
6. Image is generated and stored.
7. Ora shows the generated image result directly inside the chat thread.
8. User can:
    * download
    * save to image library
    * regenerate
    * create variation
    * delete
    * later use in project

For Phase 9A-1, the priority should be:

* Ora can generate text-to-image from chat
* generated images appear inside Ora chat
* image generation uses backend provider abstraction
* image is saved to the image asset table/storage
* user can download the image from Ora
* ownership and auth are enforced
* provider key stays server-side only
* credits and rate limits apply
* no image editing yet

The standalone /image-studio page is still useful, but it should not be the only way to generate images.

Phase 9A-1 should support both:

A. Ora chat image generation
B. Image Studio page text-to-image generation

But if we need to prioritize one, prioritize Ora chat generation first because the goal is for Ora to create pictures like ChatGPT.

Important:

Do not make Ora only reply with instructions like “go to Image Studio.”

Ora should actually generate the image through the backend tool and show the result in chat.

Image result message in Ora should include:

* generated image preview
* prompt used
* style/purpose/size
* download button
* save status
* regenerate button if supported
* safety/cost message if blocked or failed
