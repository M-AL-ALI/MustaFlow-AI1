PHASE 7B-3 — PDF GENERATION (APPROVED)

Objective

Complete the Ora export ecosystem by adding professional PDF generation while preserving the existing privacy model, bundle performance, and reporting architecture established in Phases 7B-1, 7B-2, and 7B-4A.

Current Baseline

Completed:

* Markdown export
* JSON export
* CSV export
* DOCX export
* XLSX export
* PPTX export
* Professional report templates
* Cover pages
* KPI scorecards
* Priority matrices
* Improvement roadmaps

Missing:

* PDF export

Implementation Strategy

Use browser-native print rendering.

Do NOT introduce:

* jsPDF
* pdf-lib
* Puppeteer
* Playwright PDF generation
* external PDF APIs
* server-side PDF generation

Reason:

* preserves privacy
* zero server cost
* better typography
* better table rendering
* lower maintenance
* no large dependency footprint

Architecture

Create:

artifacts/mustaflow/src/lib/file-generation/
generate-pdf.ts
print-styles.ts

Create:

artifacts/mustaflow/src/components/ora/
report-print-template.tsx

Modify:

artifacts/mustaflow/src/components/ora/ora-export-menu.tsx

No backend files.

No DB changes.

No OpenAPI changes.

No API routes.

No Knowledge Vault integration.

No reportMode work.

PDF Workflow

User clicks:

Export → PDF Report

System:

1. Build sanitized report model
2. Render hidden print document
3. Apply dedicated print stylesheet
4. Trigger browser print dialog
5. User selects:
    * Save as PDF
    * Print
6. Cleanup temporary DOM
