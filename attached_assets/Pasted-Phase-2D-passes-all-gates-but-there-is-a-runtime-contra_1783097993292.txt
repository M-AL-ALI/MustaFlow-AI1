Fix website/mobile host status and permission mode types to match the backend.

Backend contract:
status:
- online
- offline
- revoked

permissionMode:
- read_only
- ask_everything
- ask_risky
- trusted_project
- full_access
- custom

Currently wrong in:
- artifacts/mustaflow/src/pages/mode-select.tsx
- artifacts/mustaflow/src/pages/orax-devices.tsx
- artifacts/ora-mobile/lib/types.ts
- artifacts/ora-mobile/app/(home)/orax.tsx

Problems:
- Web filters hosts with h.status === "active", but backend never returns "active".
- Mobile filters hosts with h.status === "active", but backend never returns "active".
- Device settings page sends permission modes "ask", "manual", "auto", but backend rejects those because patchHostSchema expects the real backend enum.

   "online" | "offline" | "revoked"

   Instead of:
   hosts.filter((h) => h.status === "active")

   hosts.filter((h) => h.status !== "revoked")

4. Update online detection:
   Use both:
   h.status === "online"

   - read_only
   - ask_everything
   - ask_risky
   - trusted_project
   - full_access
   - custom

6. Update mobile DesktopConnectionCard to use the same backend status and permission enums.

7. Add wiring/test assertions that ban:
   status: "active"
   status === "active"
   permissionMode: "ask" | "manual" | "auto" in Orax host/device types

8. Add assertions requiring:
   "ask_risky"
