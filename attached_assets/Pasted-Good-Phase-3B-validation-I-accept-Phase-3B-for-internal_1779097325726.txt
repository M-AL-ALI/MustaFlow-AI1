TASK 2 — PRODUCTION PUBLISH GATE
==================================================

Production publish must validate requirements before allowing publish.

Required checks:
- Project has at least one generated file.
- Required production secrets are present if the app needs integrations.
- No test-looking keys in production environment.
- No production-looking keys in testing environment.
- Latest build/test report exists.
- Rollback point exists.
- Public metadata exists: title, description, favicon/logo placeholder.
- User confirms production publish.

If checks fail:
- Show clear blocker list.
- Do not publish production.
- Allow testing publish if safe.

Acceptance:
- Testing publish can run with lighter checks.
- Production publish blocks missing required production items.
- UI clearly shows pass/fail checklist.
- Deployment log records all checks.
