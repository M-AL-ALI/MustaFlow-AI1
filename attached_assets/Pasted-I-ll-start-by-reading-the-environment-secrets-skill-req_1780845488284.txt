Good question — these come from an email-sending service, not from MustaFlow. You sign up with one provider, and it gives you the host/username/password to paste into that form. Here are the easiest options:

Option 1 — Brevo (easiest, free tier ~300 emails/day)
Go to brevo.com → create a free account.
In the dashboard, open SMTP & API (under your account menu / "Transactional" → "SMTP").
It shows you exactly:
SMTP_HOST = smtp-relay.brevo.com
SMTP_PORT = 587
SMTP_USER = the login it displays (your Brevo email)
SMTP_PASS = click "Generate a new SMTP key" → copy that key
SMTP_SECURE = false
SMTP_FROM = an email you verify in Brevo under Senders (e.g. your own address)
Option 2 — SendGrid (popular, free tier ~100 emails/day)
Go to sendgrid.com → sign up → verify a sender under Settings → Sender Authentication.
Settings → API Keys → Create API Key (Full Access).
Use:
SMTP_HOST = smtp.sendgrid.net
SMTP_PORT = 587
SMTP_USER = the literal word apikey
SMTP_PASS = the API key you just created
SMTP_SECURE = false
SMTP_FROM = the sender email you verified
Option 3 — Gmail (if you already have a Gmail account)
Enable 2-Step Verification on your Google account.
Go to myaccount.google.com/apppasswords → create an App Password.
Use:
SMTP_HOST = smtp.gmail.com
SMTP_PORT = 587
SMTP_USER = your full Gmail address
SMTP_PASS = the 16-character app password
SMTP_SECURE = false
SMTP_FROM = your Gmail address
In all cases, SUPPORT_EMAIL stays Mustafa_alali74@yahoo.com — that's just where escalation emails get delivered, and Yahoo receiving them is fine.

One note: don't use Yahoo itself as the sending host — it blocks third-party SMTP. Pick one of the three above as the sender.
