Do not touch Ora, public-ai chat, AI Builder, credits, or normal project chat.

Required DB/schema changes:

1. Preserve/rename the old local-folder concept.
   The current oraxProjectsTable is actually a local desktop folder table:
   - hostId not null
   - localPath not null
   - displayName
   This should not be the cloud project table anymore.

   Rename its TS export to something like:
   - oraxDesktopLocalFoldersTable

   SQL table compatibility may be handled carefully, but the TypeScript model must not confuse local folders with cloud projects.

2. Add real cloud project table:
   oraxProjectsTable
   Fields:
   - id
   - userId not null
   - name not null
   - description nullable
   - icon nullable
   - color nullable
   - status: active | archived
   - defaultExecutionSourceId nullable
   - memory jsonb default {}
   - settings jsonb default {}
   - createdAt
   - updatedAt

3. Add project sources table:
   oraxProjectSourcesTable
   Fields:
   - id
   - projectId not null
   - userId not null
   - hostId nullable
   - type/kind: local_folder | github_repo | worktree | cloud_env | ssh_host
   - displayName not null
   - localPath nullable
   - repoUrl nullable
   - branch nullable
   - worktreePath nullable
   - status: active | missing | disconnected | archived
   - metadata jsonb default {}
   - lastSeenAt nullable
   - createdAt
   - updatedAt

4. Update oraxThreadsTable:
   - projectId
   - executionSourceId
   - mode: local | worktree | cloud | ssh | chat_only
   - userId
   - hostId nullable
   - title
   - status
