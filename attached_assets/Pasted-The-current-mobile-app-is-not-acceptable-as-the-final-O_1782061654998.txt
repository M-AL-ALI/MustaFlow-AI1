The current mobile app is not acceptable as the final Ora mobile product. TestFlight can stay internal, but we need a parity rebuild.

Goal:
Make Ora Mobile a native mobile mirror of the website Ora platform. The website Ora implementation is the source of truth.

Requirements:
1. Use the same Ora logo, brand, dark theme, colors, naming, and visual identity as the website.
2. Mobile must use the same backend AI routing logic as the website for OpenAI/ChatGPT, Gemini, DeepSeek, and other providers. Do not create separate mobile-only routing.
3. Mobile must match website functionality:
   - Ora chat
   - model/mode routing
   - projects
   - conversations/history
   - memory
   - library/assets
   - file upload and analysis
   - image upload, generation, and editing
   - generated documents/files
   - voice input and read-aloud
   - sources/media cards
   - message actions
   - temporary chat
   - ORAX
   - settings
   - plan/usage/billing state
4. Mobile UX should be native and ChatGPT-style:
   - main chat screen
   - drawer for history/projects
   - bottom composer
   - plus/tools menu
   - mic/voice button
   - long-press message actions
   - native settings, memory, billing, and library screens
5. Create a parity checklist comparing website Ora vs mobile Ora:
   Website feature | Mobile status | Missing work | Priority.
6. Refactor mobile to share or mirror the website Ora contracts:
   - message types
   - billing/plan types
   - memory types
   - project/conversation types
   - API response shapes
   - feature flags/entitlements
7. Billing must be reviewed before public App Store/Play Store release. Mobile can show current plan and usage, but paid upgrades inside the app may require Apple IAP / Google Play Billing.
8. Add testing before the next TestFlight build:
   - typecheck
   - mobile smoke test
   - auth test
   - chat test
   - file/image test
   - memory test
   - billing state test

Do not continue small random patches. First produce the parity checklist and implementation plan, then rebuild the mobile app against website Ora as the source of truth.
