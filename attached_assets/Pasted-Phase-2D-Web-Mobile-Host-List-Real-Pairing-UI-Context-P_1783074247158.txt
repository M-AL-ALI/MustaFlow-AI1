Part A — Website Orax card / entry flow

1. Update the Orax card on the MustaFlow website/dashboard.
The Orax card should behave based on real host state:

State 1: No Orax Desktop installed/registered
- Show Orax logo.
- Title: “Orax Desktop”
- Status: “Not connected”
- CTA: “Download Orax Desktop”
- Secondary text: “Install Orax Desktop on your computer to start coding with Orax.”

State 2: Desktop registered but offline
- Show connected computer name.
- Status: “Offline”
- CTA: “Open setup”
- Secondary CTA: “Download again”
- Text: “This computer is not currently online. Open Orax Desktop on your computer to reconnect.”

State 3: Desktop online
- Show computer name.
- Status: “Online”
- CTA: “Open Orax”
- Secondary CTA: “Manage devices”
- Text: “Your desktop is connected and ready.”

State 4: Multiple desktops
- Show latest active desktop.
- Add dropdown or device list.
- Show all registered hosts with:
  - deviceName
  - platform
  - status
  - lastSeenAt
  - permissionMode
  - revoke/manage action

2. The Orax card must call:
GET /api/orax/hosts

3. The Orax card must not be static anymore.
It should not always just route to /orax-product.
Instead:
- If no host exists → route to /orax-product or download/setup page.
- If host exists but offline → route to desktop setup/manage page.
- If host online → route to Orax workspace connected to that host.

4. Add loading and error states:
- Loading: “Checking Orax Desktop…”
- Error: “Could not load Orax Desktop status”
- Empty: “Install Orax Desktop to get started”

5. Keep the Orax product/download page.
Do not remove it. It is still needed for first-time users.

Permission mode behavior:

- Call PATCH /api/orax/hosts/:hostId.
- Show current mode clearly.

Part C — Pairing UI on website

For each online host:
- Add “Pair mobile device” button.
- Call POST /api/orax/pairing-codes.
- Show:
  - 6-character code
  - QR payload placeholder or actual QR if QR library already exists
  - Expires in countdown
  - Cancel button
- Cancel calls DELETE /api/orax/pairing-codes/:code.

Do not implement mobile camera scanning yet if it requires native permissions. If QR generation is simple, generate QR on web. If not, show QR payload placeholder and manual code.
