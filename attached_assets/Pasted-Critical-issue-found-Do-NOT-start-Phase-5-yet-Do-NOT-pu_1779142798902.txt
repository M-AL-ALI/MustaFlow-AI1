==================================================
TASK 1 — IMPLEMENT PUBLISH ROUTE HANDLER
==================================================

Add a real route file if missing, for example:

artifacts/api-server/src/routes/publish.ts

or add the handlers to the correct existing routes file.

Required endpoints:

POST /api/projects/:id/publish
POST /api/projects/:id/unpublish

Both must use:
- requireAuth
- requireProjectOwnership
- publish rate limiter
- JSON responses only

The publish endpoint must:

1. Validate project ownership.
2. Confirm project is not deleted.
3. Confirm project has generated files.
4. Run production/testing readiness checks if available.
5. Freeze current project_files into a project_versions.files_snapshot row.
6. Generate publicSlug on first publish if missing.
7. Preserve existing publicSlug on republish.
8. Set projects.status = "published".
9. Set projects.published_snapshot_id = new snapshot version ID.
10. Write deployment_logs row.
11. Write Knowledge Vault entry.
12. Return public URL.

Response example:

{
  "ok": true,
  "projectId": 5,
  "status": "published",
  "publicSlug": "abc-unique-slug",
  "publicUrl": "https://abc-unique-slug.mustaflow.app",
  "snapshotVersionId": 12,
  "filesPublished": 4
}

TASK 2 — IMPLEMENT UNPUBLISH ROUTE HANDLER
==================================================

The unpublish endpoint must:

1. Validate project ownership.
2. Confirm project is not deleted.
3. Set projects.status = "testing" or "draft".

5. Keep publicSlug reserved for future republish.
6. Write deployment_logs row.
7. Write Knowledge Vault entry.

Response example:

{
  "ok": true,
  "projectId": 5,
  "status": "testing",
  "publicSlug": "abc-unique-slug",
  "publicUrlDisabled": true
}
