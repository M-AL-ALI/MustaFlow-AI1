Add this to the speaker-focus / Talk to Ora QA and implementation requirements:

Other languages must be supported, not only English and Arabic.

Language requirements:
- Focus mode must work with English, Arabic, Spanish, French, Portuguese, German, Italian, Turkish, Hindi/Urdu, and any supported language Ora can understand.
- The focus filter must not depend only on English words like “what”, “how”, “can”, “tell”, or only the Latin wake word “Ora”.
- Non-English first turns must still be accepted during the start-of-session engagement window.
- Non-English follow-up turns must still be accepted inside the focus window.
- Background speech in any language must not switch Ora’s reply language unless that speech is accepted as the real user turn.
- If the user explicitly selected a reply language, Ora must stay in that language.
- If language is Auto, only accepted user turns may influence the language. Rejected side speech must not.

Implementation note:
The current start-of-session focus window is important because addressed/directed-language detection is English-biased. Do not remove it unless multilingual directed-speech detection is added.

QA additions:
Test at least these language cases:

1. English main user, Spanish background speaker
Expected:
Ora stays English and ignores Spanish background speech.

2. Arabic main user, English background speaker
Expected:
Ora stays Arabic and ignores English background speech.

3. Spanish main user
Expected:
Ora accepts the first Spanish turn and replies in Spanish.

4. French main user
Expected:
Ora accepts the first French turn and replies in French.

5. User-selected reply language
Set reply language manually, then have background speech in a different language.
Expected:
Ora keeps the selected reply language.

6. Auto language
Speak one valid turn in the target language.
Expected:
Ora replies in that language.
Then background speaker uses another language.
Expected:
Ora does not switch unless that background speech is accepted as the real user turn.

Do not make the focus scorer English-only.
Do not let rejected side speech affect language.
