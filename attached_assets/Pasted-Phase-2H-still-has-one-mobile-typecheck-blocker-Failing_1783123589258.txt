Phase 2H still has one mobile typecheck blocker.

Failing command:

pnpm --filter @workspace/ora-mobile run typecheck

Errors:

artifacts/ora-mobile/app/(home)/orax.tsx around line 448:
- Property 'canExecute' does not exist
- Property 'mode' does not exist
- Property 'blockReason' does not exist
- Property 'host' does not exist

Root cause:
getProjectThreadContext(projectId, threadId) returns:

{
  context: {
    canExecute,
    mode,
    blockReason,
    host
  },
  threadMode
}

But app/(home)/orax.tsx treats the whole response as if it were the context directly.

Current wrong pattern:

const ctx = await getProjectThreadContext(projectId, threadId);

setProjectThreadCtx({
  canExecute: ctx.canExecute,
  mode: ctx.mode,
  blockReason: ctx.blockReason ?? null,
  host: ctx.host ? { deviceName: ctx.host.deviceName ?? "Desktop" } : null,
});

Required fix:

const ctxResult = await getProjectThreadContext(projectId, threadId);
const ctx = ctxResult.context;

setProjectThreadCtx({
  canExecute: ctx.canExecute,
  mode: ctx.mode,
  blockReason: ctx.blockReason ?? null,
  host: ctx.host ? { deviceName: ctx.host.deviceName ?? "Desktop" } : null,
});
