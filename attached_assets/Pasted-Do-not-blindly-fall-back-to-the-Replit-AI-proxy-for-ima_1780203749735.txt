Do not blindly fall back to the Replit AI proxy for image generation.

The reason Ora says it cannot generate images is because isImageProviderConfigured() is returning false. That means the image provider cannot find a valid server-side image API key.

Before changing the code, please verify the current environment variables.

Check whether the API server has one of these secrets available:

* OPENAI_IMAGE_API_KEY
* OPENAI_API_KEY
* IMAGE_API_KEY

Preferred setup:

1. OPENAI_IMAGE_API_KEY for image generation
2. fallback to OPENAI_API_KEY
3. only use Replit AI integration proxy if the exact image generation endpoint and model are verified to work

Important:

We already learned the Replit AI proxy did not support embeddings. Do not repeat the same mistake with image generation.

Do not assume:

AI_INTEGRATIONS_OPENAI_BASE_URL + AI_INTEGRATIONS_OPENAI_API_KEY

supports image generation.
