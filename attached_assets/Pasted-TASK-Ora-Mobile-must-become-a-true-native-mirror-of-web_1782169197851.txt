PHASE 2 — Rebuild mobile chat composer to match website Ora

Current problem:
Mobile composer still uses separate plus button, mic button, input pill, and send button. Website Ora uses one unified rounded composer bar.

Required fix:
Rebuild the mobile composer so it mirrors website Ora:

- One unified rounded composer container.
- Plus/tools button inside the same composer bar.
- Mode indicator/tools inside same visual system.
- Mic/dictation button inside the composer bar.
- Text input inside same composer bar.
- Send button inside same composer bar.
- Focus border/ring must use Ora tier accent color, same as website.
- Composer must support multiline input and grow up to the same practical height.
- It must work in light mode and dark mode.
- It must respect safe area, keyboard avoidance, and mobile touch targets.
- It must not look like separate floating controls.

Use website Ora composer layout from ora-panel.tsx as source of truth, then translate to React Native.

PHASE 3 — Mic dictation parity

Website behavior:
Normal mic dictation records user speech, transcribes it, places transcript in the composer, and lets the user review/send manually.

Required mobile behavior:
- Mic button starts/stops recording.
- Show live recording/transcribing state similar to website OraVoiceLiveArea.
- On normal dictation, do NOT auto-send.
- Insert transcript into composer input.
- User can edit before sending.
- Show permission errors clearly.
- Show transcription errors clearly.
- Must work in light and dark mode.
- Active mic state must use Ora tier accent color.
- Must include accessibility labels.

PHASE 4 — Talk to Ora parity

Website behavior:
Talk to Ora / Voice Conversation Mode is a separate live voice mode:
- User speaks.
- Ora transcribes.
- Transcript is sent automatically.
- Ora replies.
- Ora reads the reply aloud.
- Listening restarts automatically.
- User can mute, interrupt, or end.

Required mobile behavior:
- Header Talk to Ora button must visually match website voice mode button as closely as native allows.
- Active Talk to Ora panel must mirror website OraVoiceConvPanel:
  - branded Ora look
  - rounded panel
  - tier accent border/background
  - listening/speaking/thinking states
  - mute/unmute
  - interrupt
  - end
  - auto-listening status
- Normal mic dictation and Talk to Ora must remain separate modes.
- Talk mode should auto-send transcript.
- Talk mode should auto-read Ora reply.
- Interrupt must stop TTS immediately.
- Mute must stop auto-read but keep conversation mode active.
- End must stop recording/TTS/timers and exit mode cleanly.
- Must work in light/dark mode.
- Must be tested on real device.
