Proceed to Phase 5: Multi-File Intelligence.

Do not publish. Do not submit TestFlight.

Goal:
Ora should intelligently work across multiple uploaded files instead of only one file at a time.

Use cases:
- Use Excel data to update a PowerPoint.
- Compare two Word documents/contracts.
- Merge multiple Word reports.
- Summarize multiple PDFs.
- Create a dashboard from multiple spreadsheets.
- Create a report from ZIP + documents.
- Compare two versions of the same file.
- Ask clarification if the user references “the file” or “the presentation” ambiguously.

Requirements:
1. Audit current multi-file upload/reference handling:
   - documentRefs
   - carried document context
   - file-store
   - revision history
   - file edit planner
   - chat route
   - generate-file route
   - website upload state
   - mobile upload state

2. Add a multi-file planner:
   - detect when the user intent requires multiple files
   - classify file roles:
     - source data
     - target document
     - target presentation
     - comparison file A/B
     - merge inputs
     - reference material
   - infer output format
   - detect ambiguity
   - request clarification when needed

3. Supported workflows:
   - XLSX + PPTX → update presentation using spreadsheet data
   - DOCX + DOCX → compare contracts/documents
   - DOCX + DOCX → merge reports
   - XLSX + XLSX → combine/compare spreadsheets
   - PDF/DOCX/PPTX set → create summary report
   - ZIP + files → produce analysis/report

4. Clarification behavior:
   - If multiple candidate target files exist, ask which file to edit.
   - If source vs target is unclear, ask one clear question.
   - Preserve all documentRefs while waiting for clarification.
   - Clarification follow-up resumes the original task.

5. Backend:
   - multi-file planner module
   - route integration before generic file generation
   - use latest revision head when selecting files
   - preserve project/conversation context if present
   - never silently pick the wrong file if ambiguous
   - no cross-user or cross-project leakage

6. Website:
   - show selected source files when multi-file task starts
   - show clarification question if file roles are ambiguous
   - preserve file refs through retry/stream fallback/session refresh

7. Mobile:
   - same behavior as website
   - preserve documentRefs in normal send, retry, stream fallback, and session recovery
   - compact UI for selected files/clarification

8. Tests:
   - Excel + PowerPoint routes to multi-file workflow
   - two DOCX compare routes correctly
   - two DOCX merge routes correctly
   - multiple spreadsheets combine/compare
   - ambiguous target asks clarification
   - clarification follow-up resumes multi-file task
   - latest revision head is used
   - documentRefs preserved website/mobile
   - no cross-user leakage
