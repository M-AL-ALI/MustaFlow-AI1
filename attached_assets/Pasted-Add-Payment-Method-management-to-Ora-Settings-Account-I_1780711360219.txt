Add Payment Method management to Ora Settings → Account Information.

Goal:
Users should see and manage their payment method from Ora Settings without going to AI Builder billing.

Location:
- /ora/settings
- Account Information section
- Plan & Billing / Payment Method subsection

UI should show:
1. Account email
2. Password/change password area
3. Current Ora plan
4. Renewal/due date
5. Payment method:
   - Card brand
   - Last 4 digits
   - Expiration month/year
   - Status: active / missing / expired if available
   - Buttons:
     - Add payment method
     - Change payment method
     - Manage billing

Security:
- Do not collect raw card details inside MustaFlow.
- Do not store card number, CVC, or full payment data.
- Use Stripe-hosted flows only.

Backend:
Add or reuse endpoints:

1. GET /api/billing/payment-method
Return:
{
  hasPaymentMethod: boolean,
  brand?: string,
  last4?: string,
  expMonth?: number,
  expYear?: number,
  customerId?: string,
  plan?: string,
  renewalDate?: string | null,
  cancelAtPeriodEnd?: boolean
}

2. POST /api/billing/portal
Use this for paid users or users with an existing Stripe customer.
Return Stripe Customer Portal URL.

3. Optional if needed:
POST /api/billing/payment-method/setup
Create a Stripe SetupIntent or Stripe Checkout setup session for users who need to add a payment method without upgrading yet.

Behavior:
- Free user with no payment method:
  Show "No payment method on file."
  Primary action: "Upgrade plan"
  Secondary action only if supported: "Add payment method"

- Paid user:
  Show current payment method.
  Button: "Change payment method"
  This opens Stripe Customer Portal.

- Paid user with missing/default payment method:
  Show warning: "Payment method required."
  Button: "Add payment method"

- Cancel-at-period-end user:
  Show plan status and renewal/end date clearly.

Important separation:
- This must stay inside Ora Settings.
- Do not link to the AI Builder billing dashboard.
- Do not use Builder credit wording.
- Use Ora plan language: Free, Core Pack, Deep Wave.

Acceptance:
- /ora/settings shows payment method information.
- Add/change payment method opens Stripe-hosted flow.
- No raw card data is stored or handled by MustaFlow.
- Current plan and due/renewal date display correctly.
- Free/Core/Wave behavior is correct.
- No Ora surface routes users to AI Builder billing.
- Typecheck, lint, format, and relevant billing tests pass.
