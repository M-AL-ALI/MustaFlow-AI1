2. Create a real provisioning endpoint

Add or verify a backend endpoint like:

POST /api/projects/:id/container/provision

POST /api/projects/:id/workspace/provision

This endpoint must:

* verify auth/project ownership
* verify builder_mode = agentic
* create or repair the Fly.io container
* assign project.containerId
* create workspace filesystem
* install starter files if missing
* install dependencies if needed
* start/wake container
* run workspace proof test
* start preview server
* update DB status
* return structured result

Required DB updates:

When provisioning starts:

* provisioning_status = "provisioning"
* container_status = "starting"
* container_error = null
* developer_ready = false

When provisioning succeeds:

* provisioning_status = "ready"
* container_status = "running"
* containerId = created container id
* developer_ready = true
* container_ready_at = now()
* container_error = null

When provisioning fails:

* provisioning_status = "failed"
* container_status = "failed"
* developer_ready = false
* container_error = exact reason
* container_failed_at = now()
