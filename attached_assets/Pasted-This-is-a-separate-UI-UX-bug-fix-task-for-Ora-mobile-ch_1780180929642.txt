This is a separate UI/UX bug-fix task for Ora mobile chat. Please do not mix it with Phase 7B-3, Phase 8B, or any other roadmap work.

Issue summary:
Users are reporting that when they open Ora through the “Ask Ora” button, the mobile chat layout is broken. The assistant reply text is overlapping near/on top of the chat composer area, the message thread is not scrolling correctly, and users cannot properly scroll down through the conversation. This is happening on mobile and must be fixed for both iPhone and Android.

Problems to fix:

1. Assistant/user text is overlapping the composer/input area.
2. The message thread is not scrolling correctly when Ora is opened through the “Ask Ora” button.
3. Users cannot reliably scroll down to newer messages.
4. The keyboard open state may be pushing or compressing the layout incorrectly.
5. The composer may be overlaying the messages.
6. The upload hint/message count area must not overlap the chat content.
7. The floating “Ask Ora” button must not interfere with the open Ora panel/drawer.
8. The open Ora drawer/panel must behave correctly on mobile safe areas and viewport changes.

Very important:
Please test and fix this on both iPhone and Android, not only one platform.

Required device/browser validation:

* iPhone Safari
* iPhone Chrome
* Android Chrome
* Android Samsung Internet if possible

Expected behavior after the fix:

* The Ora message thread must be a proper scroll container.
* Messages must remain visually above the composer, never underneath it.
* The latest message must always be reachable.
* Auto-scroll should work correctly when appropriate.
* Manual scrolling through previous messages must work correctly.
* When the keyboard opens, the layout must remain stable.
* The composer must remain visible and usable.
* No assistant text should overlap the chat box/input/composer.
* No upload hint, footer text, or message counter should overlap the thread content.
* The floating Ask Ora trigger must not cover the open Ora chat UI.
* Safe-area / viewport handling must work correctly on iPhone and Android.

Please inspect and fix:

* The scroll container structure for the Ask Ora mobile panel/drawer
