Accepted route:

POST /api/vault/search/semantic

Accepted backend behavior:

* route is authenticated
* route is not public
* route is not under /api/public-ai
* request body is Zod-validated
* invalid requests return safe validation errors
* ownership is enforced on both vault_entries and vault_embeddings
* search only returns authenticated user’s own vault data

Accepted embedding/search behavior:

* user query is embedded with text-embedding-3-small
* query vector dimension is 1536
* only the search query is sent to the embedding model
* vault entry content is not sent to the model during search
* search compares query embedding against vault_embeddings.embedding
* pgvector cosine distance operator is used
* results are ranked by closest vector match
* DISTINCT ON (entry_id) prevents duplicate entry spam
* each result returns one best-matching chunk per entry
* similarity score is normalized to 0–100
* result limit is enforced
* chunk preview is capped to 300 characters

Accepted filters:

* category filter
* department filter
* tags filter
* status filter
* include archived filter
* limit parameter
* ownership filter

* Keyword / Semantic toggle added

* similarity score displayed

* title/category/department/tags/summary/date displayed
* clicking result opens existing entry viewer
* no-embeddings state added
* no-results state added
* reindex button shown when no embeddings exist
* embedding/search errors handled safely
* raw vectors are never shown

Accepted privacy/security proof:

* raw vectors are never returned
* raw vectors are never logged
* chunk text is not logged
* query text is not logged
* vault content is not sent to the model during search
* public Ora cannot access semantic search
* another user’s entries/chunks cannot be returned
