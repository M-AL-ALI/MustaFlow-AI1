Add GitHub and Codex support to MustaFlow AI, but keep the architecture clean.

Important:
MustaFlow platform integrations must stay hidden in the background/admin system.
The GitHub integration shown to users must be for their generated projects only.

==================================================
GITHUB PROJECT INTEGRATION
==================================================

Build GitHub as a Project Integration.

Location:
Project Workspace → Integrations → GitHub

User flow:
1. User opens a project.
2. User clicks Integrations → GitHub.
3. User clicks Connect GitHub.
4. User installs/authorizes the MustaFlow GitHub App.
5. User chooses which repository to connect.
6. User can push generated project files to GitHub.
7. User can create a new branch.
8. User can commit changes.
9. User can open a pull request.
10. User can sync latest generated files.

Use a GitHub App approach, not raw personal access tokens.

Store:
- projectId
- userId
- githubInstallationId
- githubAccountName
- repositoryOwner
- repositoryName
- defaultBranch
- lastSyncAt
- syncStatus
- createdAt
- updatedAt

Do not expose GitHub tokens to the frontend.
Use short-lived installation tokens on the server.

Required backend routes:
- GET /api/projects/:id/github/status
- POST /api/projects/:id/github/connect
- POST /api/projects/:id/github/disconnect
- GET /api/projects/:id/github/repositories
- POST /api/projects/:id/github/select-repository
- POST /api/projects/:id/github/push
- POST /api/projects/:id/github/create-branch
- POST /api/projects/:id/github/open-pr
- GET /api/projects/:id/github/sync-status

Required UI:
- GitHub connection card
- Connect / Disconnect button
- Repository selector
- Branch selector
- Push to GitHub button
- Create Pull Request button
- Last sync status
- Error messages

Acceptance:
- GitHub appears as a user project integration.
- Platform OpenAI/Clerk/Cloudflare remain hidden.
- User can connect repository to project.
- User can push generated files to GitHub.
- User can create a branch/PR.
- No raw GitHub token exposed.
