Do not add new features yet. The goal is to prove MustaFlow Mobile can produce real iOS and Android builds.

1. Security check first

Before building, verify that no private secrets are bundled into the mobile app.

Check the mobile codebase for:

* OPENAI_API_KEY
* ANTHROPIC_API_KEY
* GEMINI_API_KEY
* DEEPSEEK_API_KEY
* any server-only API key
* any non-EXPO_PUBLIC_ secret being referenced directly in client/mobile code

Important rule:

* EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY is okay.
* EXPO_PUBLIC_DOMAIN is okay.
* EXPO_PUBLIC_ORA_STREAMING_ENABLED is okay.
* Private AI provider keys must stay only on the backend/server.
* Mobile should call MustaFlow/Ora backend endpoints, not AI provider APIs directly.

If any private key is exposed to the mobile bundle, stop and fix it before building.

2. Confirm EAS environment variables

Use EAS environment variables for build profiles.

Verify or create the required variables for:

* development
* preview
* production

Required variables:

* EXPO_PUBLIC_DOMAIN
* EXPO_PUBLIC_CLERK_PUBLISHABLE_KEY
* EXPO_PUBLIC_ORA_STREAMING_ENABLED=true

For production:

* EXPO_PUBLIC_DOMAIN should be the production API/domain for MustaFlow/Ora.
* Do not include https:// if the code expects only the domain.
* Do not include a trailing slash.

After setting them, run:

eas env:list --environment development
eas env:list --environment preview
eas env:list --environment production

Report exactly what exists, but do not print private values.

3. Confirm build profile mapping

Check eas.json and confirm each build profile uses the correct environment:

* development profile uses development env
* preview profile uses preview env
* production profile uses production env

If missing, update eas.json with the correct environment field.

4. Run prebuild/config validation

Run whatever Expo validation is available for this project, for example:

npx expo-doctor
npm run typecheck

or the equivalent package-manager commands already used in this repo.

Confirm:

* app name is still MustaFlow
* icon is still the existing MustaFlow icon

5. First cloud builds

If EAS is logged in and credentials are available, run:

eas build --profile preview --platform android
eas build --profile preview --platform ios

If preview succeeds, then run production builds:

eas build --profile production --platform android
eas build --profile production --platform ios

Do not submit to the stores yet.
